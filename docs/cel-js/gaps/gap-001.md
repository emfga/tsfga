# GAP-001 — RE2 rejects, JavaScript accepts

**Direction: granting.** cel-js compiles a pattern OpenFGA will
not store, so tsfga answers a check on a model upstream does not
have.

Fourteen constructs, measured against OpenFGA v1.18.2 and cel-js
8.0.0. Full table and reasoning:
[`../regex/re2-vs-celjs.md`](../regex/re2-vs-celjs.md), group 1.
The `^[^]*$` member has its own page:
[`../regex/bypass.md`](../regex/bypass.md).

RE2 has no backtracking, so lookaround and backreferences do not
exist in it by construction — they are what buys the linear-time
guarantee, not omissions. `a{1001}` is refused so the compiled
program stays finite.

**Closed in tsfga by dropping `matches()`.** Not reachable: the
expression is refused at write.

**A fork must** make `matches` reject these patterns. A write-time
scanner can do it for a literal pattern and cannot do it for one
arriving through condition context, which is why the scanner was
authorised and then abandoned.
